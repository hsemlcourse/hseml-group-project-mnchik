## Описание задачи

**Задача:** многоклассовая классификация — прогнозирование типа лесного покрова по картографическим и природным признакам.

**Датасет:**  
Covertype, UCI Machine Learning Repository  
https://archive.ics.uci.edu/ml/datasets/covertype 

Каждая строка соответствует участку леса размером 30×30 м, описанному набором топографических и почвенных признаков (высота, уклон, освещённость, расстояние до дорог/воды/точек возгорания, тип почвы и тип охраняемой территории). Целевая переменная `Cover_Type` принимает одно из 7 значений, соответствующих разным типам лесного покрова.

**Целевая метрика:**  
Основная — **F1‑macro**, так как она одинаково учитывает качество по всем 7 классам и не позволяет модели получать высокий результат только за счёт доминирующих классов. Дополнительно оценивается **accuracy** и `F1‑weighted` для общей интерпретации качества.

## Запуск

### Локально (без Docker)

```bash
# 1. Клонировать репозиторий
git clone <url>
cd hseml-group-project-mnchik  # или имя вашего репозитория

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# .venv\Scripts\activate        # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. (Опционально) прогнать smoke-тест
pytest tests/test.py            # или: python -m tests.test

# 5. Запустить эксперименты с моделями
python -m src.models.modeling
```

После выполнения экспериментов результаты будут сохранены в `experiments/experiments.csv`.

### Через Docker

```bash
# Сборка образа и запуск
docker-compose up --build
```

Команда по умолчанию запускает модуль `src.models.modeling`, который обучает все модели и сохраняет метрики.

## Данные

- `data/raw/` — исходные данные:
  - `covertype.zip` и `covtype.data.gz` из UCI;
  - `covertype_parsed_bonus.csv` — результат самостоятельного парсинга исходного `.data` файла. 
- `data/interim/` — очищенные данные без новых признаков (`covertype_clean.csv`).
- `data/processed/` — данные после feature engineering (`covertype_features.csv`), использующиеся для обучения основных моделей.

Парсинг исходного файла `covtype.data.gz` реализован в `src/data/parse_raw.py` и позволяет воспроизвести датасет из сырого архива UCI, что используется в отчёте как пример самостоятельной работы с данным источником.

## Результаты

Наиболее важные результаты по валидационной и тестовой выборкам (метрика — F1‑macro, основная для выбора модели):

| Модель            | Val F1‑macro | Test F1‑macro | Примечание                      |
|-------------------|-------------:|--------------:|---------------------------------|
| Logistic Regression (baseline) | 0.531 | 0.530 | Линейный baseline, без фичей    |
| Linear SVC        | 0.461 | 0.456 | Линейная SVM, хуже baseline     |
| KNN (k=15)        | 0.825 | 0.830 | Лучше baseline, но тяжелее      |
| Gradient Boosting | 0.728 | 0.727 | Нелинейная модель, средний результат |
| **Random Forest (n=200)** | **0.916** | **0.917** | Лучшая модель по F1‑macro, финальный выбор |

RandomForest показал наилучшее качество как по F1‑macro, так и по accuracy, при этом остаётся достаточно устойчивым и интерпретируемым (можно анализировать важность признаков), поэтому именно он выбран в качестве финальной модели. Логистическая регрессия служит baseline‑решением, от которого видна существенная прибавка качества при переходе к ансамблевым моделям.
